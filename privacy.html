개인정보처리방침

이 방침은 정식 서비스 공개 전 단계의 안내이며, 서비스 형태가 바뀌면 함께 갱신합니다.

1. 이 소개 사이트

  • 이 사이트는 가입, 입력 양식, 댓글, 광고, 방문 분석 도구, 쿠키를 사용하지 않습니다. 방문자에 대해 우리가 수집하는 개인정보는 없습니다.
  • 사이트는 GitHub Pages에서 제공됩니다. 서버 접속 기록 등은 호스팅 사업자의 정책에 따라 처리될 수 있습니다.
  • 문의 이메일로 메일을 보내시면 답변을 위해 보내신 이메일 주소와 내용을 확인하며, 답변이 끝나면 필요한 기간이 지난 뒤 삭제합니다.

2. 테스트 참여자용 앱

서비스 앱은 이 사이트와 별도로 운영되며 초대받은 테스트 참여자만 사용합니다. 공개 회원가입은 없습니다.

  • 처리하는 정보: 로그인 계정명, 비밀번호(복원할 수 없는 해시로만 저장), 접속 세션, 사용자가 직접 입력한 업무 기록과 변경 이력.
  • 이용 목적: 로그인, 권한 관리, 서식 작성 기능 제공, 오류 대응.
  • 보관과 삭제: 테스트가 끝나면 계정과 입력 데이터를 삭제합니다. 삭제를 원하시면 문의해 주세요.
  • 운영 방식: 서비스 운영에는 클라우드 서버(Oracle Cloud)와 사설 네트워크 도구(Tailscale)를 이용하며, 초대받은 참여자만 접속할 수 있도록 운영합니다. 이용자의 업무 기록을 광고·분석 등의 목적으로 제3자에게 제공하지 않습니다.
  • 테스트에는 실제 업체 정보 대신 가짜 데이터를 사용하도록 권합니다.
