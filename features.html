기능 소개

한 번 입력한 원천 데이터에서 여러 서류를 뽑아 쓰는 것이 핵심입니다.

1. 규제 캘린더

  • 사업장 종별(대기·폐수), 유해화학물질 취급 여부 같은 설정에 맞는 항목만 표시합니다.
  • 앞으로 12개월의 제출 기한을 D-day 순서로, 지난 미완료 항목은 연체로 표시합니다.
  • 항목마다 근거 법령, 제출 시스템, 주의사항, 그리고 필요한 데이터가 얼마나 쌓였는지를 보여 줍니다.
  • 제출 상태(예정·준비중·제출완료)와 메모를 남길 수 있습니다.

2. 원천 데이터 입력과 가져오기

  • 화학물질 입고, 폐기물 반출, 폐수 배출량, 시설 가동, 자가측정 결과, 에너지 사용량, 배출구·연료·도료 정보를 날짜·항목·수량으로 기록합니다.
  • 엑셀(.xlsx)·CSV·붙여넣은 표를 컬럼 이름으로 자동 연결하고, 확인 화면을 거친 뒤에만 저장합니다. 이미 있는 기록은 중복으로 표시하고 제외합니다.
  • 세금계산서 내역의 공급가액 같은 금액 열은 수량으로 잡지 않습니다.

3. 기관 서식 원본 배치 인쇄

서식특징
반기별 자가측정 결과보고서측정항목 한 줄씩, 배출구·날짜 단위 칸 합치기, 줄이 많으면 첨부 페이지로 자동 분할
대기 측정기록부(굴뚝용)표준 서식 1-1 배치. 채취일·배출구마다 한 장, 시설가동상황 열 순서까지 표준대로
소규모사업장 대기배출원조사표기본정보 ①~⑬과 2-1~2-6, A4 2장. 표마다 비고 행

나머지 서식(화학물질 배출량조사, 폐기물 처리실적 등)은 기초자료 표를 엑셀·CSV·인쇄용으로 내려받습니다.

4. 제출 전 확인

인쇄물에는 나오지 않고 화면에만 보이는 점검 목록입니다.

  • 비어 있는 칸(제출인 정보, 배출구 번호, 측정분석방법 등)
  • 서식 규칙과 어긋난 값(가동시간 0~24, 연간 가동일수 0~365, 배출구 번호 불일치 등)
  • 측정값이 입력한 허용기준을 넘은 경우

5. 계정과 안전장치

  • 관리자·담당자·조회자 권한, 비밀번호는 Argon2 해시로 저장, 로그인 시도 제한
  • 기록 수정·삭제 이력, 삭제 기록 복원, 동시 수정 충돌 방지
  • 매일 자동 백업과 관리자 다운로드·복구
